# 去处 Somewhere

> 把一种感觉，翻译成一个地方。

「去处 Somewhere」是一个反向旅游 Agent。

传统旅行产品通常先问“你想去哪”，而 Somewhere 先理解“你想进入怎样的生活”：想要什么天气、节奏、人群距离和情绪，再为你找到值得考虑的地方。

## 它可以做什么

- 用自然语言描述旅行感觉，不需要提前知道目的地。
- 将模糊的表达整理成可理解的旅行画像：情绪、环境、节奏、社交密度和现实限制。
- 根据旅行画像动态召回三个不同角色的目的地：
  - 最符合当下状态的地方
  - 一个意外但值得考虑的选择
  - 一个更容易抵达的选择
- 展示每个目的地为什么适合你，以及它对应的现实取舍。
- 支持国内外范围、天数、预算、出发地和交通偏好等条件。
- 支持继续调整感觉，例如“再安静一点”“少一点商业化”“更容易抵达”。
- 为选中的目的地生成三日低压力提案，而不是塞满景点的标准行程。
- 在地图上查看目的地、每日路线和可编辑的行程结构。
- 按需查询天气、道路路线和附近地点，并展示来源与查询时间。
- 支持图片灵感和图片链接理解，将画面提炼成旅行偏好标签。
- 支持浏览器语音转写，帮助用户把声音和听感变成文字灵感。
- 收藏喜欢的地方，根据个人偏好重新排序候选。
- 导出一份出发决策包，整理每日安排、地图入口和出发前待确认事项。

## 一次完整体验

```text
描述感觉 → 理解偏好 → 召回目的地 → 比较取舍 → 编辑行程 → 出发前核验
```

产品不会把 AI 生成的内容伪装成实时事实。营业时间、票务、交通班次、安全和价格等信息，都会保留为出发前需要确认的事项。

## 适合谁

适合那些“不知道去哪，但知道自己最近想怎么生活”的人：

- 想独处几天的人
- 想短暂逃离熟悉环境的人
- 不喜欢热门景点和模板行程的人
- 需要一个有理由、有取舍的旅行建议的人

## 设计关键词

反向旅行、情绪理解、低压力行程、可解释推荐、现实边界、留白。
